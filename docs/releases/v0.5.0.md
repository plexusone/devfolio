# devfolio v0.5.0 Release Notes

**Release Date:** 2026-10-01

## Overview

DevFolio v0.5.0 migrates the dashboard IR dependency from `uiforge` to
`dashforge`. The `dashboardir` package moved out of `uiforge` into
`dashforge`, and `uiforge` no longer publishes the `v0.5.0` that provided
it — which left DevFolio v0.4.0 **unresolvable on a clean module fetch**
(it only built where an old `uiforge v0.5.0` was already cached). This
release repoints every `dashboardir` import to
`github.com/plexusone/dashforge/dashboardir` (same package, same types),
drops the `uiforge` dependency, and moves the `go` directive to 1.26.6 as
required by `dashforge v0.7.0`.

**This is a breaking release** — see Migration.

## Highlights

- **Restored installability** — `go get github.com/plexusone/devfolio@v0.5.0`
  resolves cleanly again; v0.4.0's transitive `uiforge/dashboardir` import can
  no longer be fetched.
- **Dashboard IR now sourced from dashforge** — `output/devxdashboard` and
  `quarterly` build against `dashforge/dashboardir`, the package's new home.

## Installation

```bash
go install github.com/plexusone/devfolio/cmd/devfolio@v0.5.0
```

## Dependencies

- Add `github.com/plexusone/dashforge v0.7.0` (provides `dashboardir`)
- Remove `github.com/plexusone/uiforge` (no longer publishes the `dashboardir`
  package)
- `go` directive 1.26.5 → 1.26.6 (required by `dashforge v0.7.0`)

## Migration

**Breaking:** the exported `output/devxdashboard` functions `Export` and
`ExportPeriod` now return `*dashforge/dashboardir.Dashboard` instead of
`*uiforge/dashboardir.Dashboard`. The struct shape is unchanged, but the Go
type identity differs by import path. Consumers that name the `dashboardir`
type must change their import:

```go
// before
import "github.com/plexusone/uiforge/dashboardir"
// after
import "github.com/plexusone/dashforge/dashboardir"
```

Consumers that only call `Export`/`ExportPeriod` and pass the result straight
to a `dashforge/dashboardir` consumer (or marshal it to JSON) need no code
change beyond bumping the DevFolio version.

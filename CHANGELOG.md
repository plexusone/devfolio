## [v0.4.0] - 2026-08-17

### Highlights

- `devfolio devx dashboard --period weekly|monthly|quarterly`: calendar-aligned period reports (Monday-Sunday weeks) with weekly/monthly per-model breakdowns, written by default to `~/.plexusone/omnidevx/reports/{type}/{label}.json` — the path VisionStudio's `/api/devx/periods` and `/api/devx/reports/{periodType}/{label}` endpoints read from
- Weekly period labels changed from ISO week numbers ("W28") to the week's Monday date ("Mon Jul 6, 2026") for human readability, with the underlying weekly buckets fixed to align to real calendar weeks
- Bump `github.com/plexusone/uiforge` to v0.5.0 (static viewer light/dark theme toggle and 2-decimal numeric formatting)

### Added

- `--period` and `--for` flags on `devfolio devx dashboard`: generate weekly/monthly/quarterly calendar reports instead of a rolling `--days` window, with weekly/monthly model breakdowns feeding the quarterly report's donut and stacked-bar widgets ([`dbfcf99`](https://github.com/plexusone/devfolio/commit/dbfcf99))

### Fixed

- `output/devxdashboard.buildStackedBarData` ignored its `metrics` argument, so the weekly/monthly cost and token stacked-bar charts silently returned identical values; `ModelPeriodPoint.Models` now carries a metric map per model so each chart pulls its own numbers ([`dbfcf99`](https://github.com/plexusone/devfolio/commit/dbfcf99))
- Resolve 4 pre-existing "error discard without comment" findings in `cmd/devfolio` and `datasource/prism` via proper return/panic handling instead of silent discard ([`2dceb0f`](https://github.com/plexusone/devfolio/commit/2dceb0f))

### Dependencies

- Bump `github.com/grokify/mogo` from v0.74.6 to v0.74.7 ([`f81f4e3`](https://github.com/plexusone/devfolio/commit/f81f4e3))
- Bump `github.com/plexusone/uiforge` from v0.4.0 to v0.5.0 ([`8fa6ec6`](https://github.com/plexusone/devfolio/commit/8fa6ec6))
- Routine transitive dependency updates via go mod tidy ([`b1b9994`](https://github.com/plexusone/devfolio/commit/b1b9994))

### Documentation

- Document `devx dashboard --period`/`--for` across README.md, docs/commands/devx.md, docs/index.md, and docs/getting-started.md; note VisionStudio's period endpoints and uiforge v0.5.0's viewer theme toggle ([`f32d76d`](https://github.com/plexusone/devfolio/commit/f32d76d))

### Internal

- Fix gofmt drift across 9 files (struct-literal alignment), surfaced by the v0.4.0 release validation gate ([`e39300b`](https://github.com/plexusone/devfolio/commit/e39300b))

## [v0.3.0] - 2026-08-02

### Highlights

- `devfolio quarterly report`: self-contained HTML reports joining GitHub stats, git commit analytics, changelog highlights, and OmniDevX token spend — inline SVG or interactive ECharts, with `--format dashboard`/`--format json` exports
- `devx dashboard` gains period reports: weekly/monthly/quarterly dashboards with model-breakdown donut charts and stacked bar charts by model
- Contributor profile: per-model AI stats (`AIModelStat`, `MostUsedModel`) bridged from `gogit.AIStats`, plus a new PRISM Control JSONL datasource
- `contributor/client.go` migrated off go-github onto `gogithub`'s version-isolated `clientv1.Client`; `github.com/google/go-github` is now only a transitive dependency

### Added

- `quarterly` package: `Report` type composing GitHub stats, git commit stats, changelog highlights, and a token-spend summary ([`976f3f8`](https://github.com/plexusone/devfolio/commit/976f3f8))

## [v0.2.0] - 2026-07-20

### Highlights

- `devfolio devx dashboard`: build a DeveloperPeriodReport from the local OmniDevX event store (Claude Code, Codex CLI, git, GitHub) and export it as a dashforge dashboard
- MkDocs documentation site, matching the rest of the OmniDevX ecosystem
- Contributor profile: local git clone detection with automatic API fallback, multi-stage progress reporting, and a dashforge dashboard export flag

### Added

- `devfolio devx dashboard` command: reads the local OmniDevX store, builds a `DeveloperPeriodReport`, exports a portable dashforge dashboard (8 metric tiles, daily activity/cost charts, source-coverage table) ([`13ec741`](https://github.com/plexusone/devfolio/commit/13ec741))
- `output/devxdashboard` package: projects a `DeveloperPeriodReport` into `dashforge`'s `dashboardir.Dashboard` type directly (not a local reimplementation), so chart widgets render correctly in dashforge's current viewer ([`7aae21c`](https://github.com/plexusone/devfolio/commit/7aae21c))
- `contributor profile --dashboard`: export a dashforge-compatible dashboard from a contributor profile (chart widgets use an older shape — see Documentation) ([`5b59e38`](https://github.com/plexusone/devfolio/commit/5b59e38))
- `contributor profile --api-only`/`--local-path`: local git clone detection (checks `~/go/src/github.com` and configured paths, falls back to the GitHub API) plus multi-stage progress reporting to stderr ([`78961b7`](https://github.com/plexusone/devfolio/commit/78961b7))
- MkDocs site: landing page, getting-started walkthrough, command reference for contributor/team/devx, PlexusOne nav override — `docs/specs/` (internal ecosystem architecture) deliberately excluded from the built site ([`a6102a8`](https://github.com/plexusone/devfolio/commit/a6102a8))
